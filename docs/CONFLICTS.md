# CONFLICTS — sources that disagree

Resolution rule: export wins for visuals, BRIEF wins for behaviour/links; everything logged here.

1. **Screenshots vs export — module device column empty.** All module-section screenshots show no phone in the right column / carousel. `screenshots/README.md` documents this as a capture artefact. → Export (and standalone render) wins: devices are present.
2. **Screenshots vs export — waitlist section missing.** The `#get` dark card appears in no screenshot (desktop set jumps from Circles copy to footer). Cause: `data-reveal` starts at `opacity:0` and the capture tool re-renders the DOM without firing the IntersectionObserver. → Export wins: the section exists and reveals on scroll.
3. **Screenshots vs export — mobile/tablet captures left-aligned in a wider canvas** (e.g. 390-wide page pinned left of a ~924-wide image). Capture artefact; layout values come from the export.
4. **Known bug, intentional deviation:** module auto-cycle advances `% 3`, so Spend's 4th panel (Subscriptions) is never auto-reached. `README.md` and `HANDOFF_INSTRUCTION.txt` both instruct fixing to per-module panel count in the rebuild. → Rebuild fixes it (behaviour differs from export by instruction). Verification must not flag this.
5. **Demo iframe target missing.** Export references `Savvy%20Bee%20Prototype.html#Home.dc.html`; the file is not in the bundle (only embedded inside the standalone bundle's blob). BRIEF §10 lists this as open. → Overlay + loader rebuilt faithfully; iframe destination stubbed pending answer (open question).
6. **About/Legal link targets missing.** `About.dc.html`, `Legal.dc.html` are linked from nav/footer but explicitly out of scope and not shipped. → Hrefs kept verbatim pending answer (open question 18).
7. **Buttons are `<div>`/`<a>` with `cursor:pointer`, input has `outline:none`, images with empty `alt`.** The rebuild's accessibility requirements (semantic buttons, focus states) alter markup but must not change rendered appearance at rest. Focus-visible styles are an addition the export does not define (BRIEF open questions 4–5).
8. **BRIEF says GTBank "Other" ₦23k / source value 22500; Kuda "Other" ₦7k / 7300.** Not a conflict — the compact formatter (`round(n/1000)`) yields ₦23k/₦7k. Recorded to explain the figures.
9. **Standalone `<title>` is "Bundled Page"** (bundler artefact); BRIEF §9 says no title exists and suggests one. → Rebuild uses BRIEF's suggested title (behaviour/meta = BRIEF's domain).
10. **BRIEF vs export — link hover.** BRIEF §3.0/§5 says nav/footer links hover to `#B8860B` via the global `a:hover` rule. In the export those links carry **inline** `color:#6B6860`, which the stylesheet hover rule cannot override — so they never actually change colour on hover; only links without inline colour (the brand lockup) do. The rebuild mirrors the export's rendered behaviour (no hover change on nav/footer links, amber hover on the brand) and notes BRIEF's description as inaccurate to the cascade.
11. **Legal page tab anchors have no target elements — by design.** The export's tab strip uses `<a href="#terms">` etc., but no element carries those ids; the hash change is caught by a `hashchange` listener that switches the document and scrolls to top. Reproduced exactly (deep links work; there is intentionally no in-page anchor jump).
12. **Legal `noindex` (build decision, later reverted).** The first rebuild added `robots noindex` to the legal stub. The updated handoff ships Legal as a linked, in-scope page whose designed draft mitigation is the visible DRAFT FOR REVIEW banner — so the rebuild removed `noindex` and relies on the banner, per the export. Re-add it only if counsel wants the page uncrawlable until sign-off.
13. **Client addition — About hero video (post-handoff change request).** A YouTube Short (`iDice Application by Savvy Bee Limited`, `umwO_zeVJwM`) was embedded in the About hero, left of the copy, at the client's request on 16 Sep 2026. Not in the design export; styled to the system (9:16, 12px radius, mono caption, team-row grid pattern; privacy-enhanced `youtube-nocookie.com` embed, lazy-loaded). The verification suite treats the About hero as a sanctioned deviation and pixel-checks the sections below it instead.
14. **BRIEF §3.1 states scope-list/dots active colour**: BRIEF's token table calls active dots `#B8860B`, and the hero **carousel** dots use `#1C1917` when active (source: `heroDots` bg `#1C1917`), while the scope-row dot uses amber. Both kept exactly as source.
